## 👩‍💻 About me

I'm an Agentic AI Developer. I build AI agents in Python that do real work for businesses — answering customer questions from their own documents, qualifying leads, handling booking requests, and following up automatically. Every agent is tested on sample data first, and nothing acts without human approval.
